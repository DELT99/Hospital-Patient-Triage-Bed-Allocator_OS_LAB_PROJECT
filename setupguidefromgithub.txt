download the zip in ubuntu with firefox
STEP 1 — Open Terminal
Press Ctrl + Alt + T

A black window opens.

STEP 2 — Install GCC and Make
Type this exactly and press Enter:

bash
sudo apt install gcc make -y


Wait until it finishes. You will see the cursor come back.

STEP 3 — Go to Downloads Folder
bash
cd ~/Downloads
Press Enter.

STEP 4 — Confirm Your Zip is There
bash
ls
Press Enter. You will see your zip file listed:

OS_Lab_Project.zip
If you see it, continue. If not, your zip might be on Desktop:

bash
cd ~/Desktop
ls
STEP 5 — Extract the Zip
bash

...
STEP 6 — Go Inside the Project Folder
bash
cd OS_Lab_Project
Press Enter.

STEP 7 — Confirm All Files Are There
bash
ls
You should see:

Makefile  README.txt  logs  report.pdf  scripts  self_eval.pdf  src
Also check inside src and scripts:

bash
ls src/
ls scripts/
src:
admissions.c  hospital.h  patient_simulator.c

scripts:
start_hospital.sh  stop_hospital.sh  stress_test.sh  triage.sh
STEP 8 — Fix Script Permissions
bash
chmod +x scripts/*.sh
Press Enter. No output is normal — means it worked.

STEP 9 — Build the Project
bash
make clean
Then:

bash
make
You should see:

gcc -Wall -Wextra -g -pthread -Isrc -o admissions src/admissions.c -lpthread
  [OK] admissions
gcc -Wall -Wextra -g -pthread -Isrc -o patient_simulator src/patient_simulator.c
  [OK] patient_simulator
Build complete.
If you see this — your project compiled successfully.

STEP 10 — Open a Second Terminal
Press Ctrl + Alt + T again.

Now you have 2 terminal windows.

Keep them both open side by side.

STEP 11 — Terminal 1 — Start the Hospital
In Terminal 1 type:

bash
cd ~/Downloads/OS_Lab_Project
make run
You will see:

╔══════════════════════════════════════════╗
║  HOSPITAL PATIENT TRIAGE & BED ALLOCATOR ║
╚══════════════════════════════════════════╝
[START] Launching admissions manager...
[INIT]  Ward ready: 4 ICU + 4 Isolation + 12 General
[RECEP] Receptionist started
[SCHED] Scheduler started
[NURSE] ICU nurse started
[NURSE] ISOLATION nurse started
[NURSE] GENERAL nurse started

=== HOSPITAL IS OPEN — Waiting for patients ===
Leave Terminal 1 running. Do not close it.

STEP 12 — Terminal 2 — Send a Patient
Go to Terminal 2 and type:

bash
cd ~/Downloads/OS_Lab_Project
./scripts/triage.sh "Ali Raza" 28 10 0
Now look at Terminal 1 — you will see:

[RECEP] #1 Ali Raza | age=28 sev=10 pri=1 ICU
[QUEUE] Enqueued #1 (Ali Raza) priority=1
[SCHED] Admitting #1 (Ali Raza) -> ICU
[ALLOC] Patient #1 -> partition 0 (ICU, 3 units)
[FORK ] PID=XXXX spawned for patient #1
[PATIENT #1] Ali Raza arrived — type: ICU
[PATIENT #1] Ali Raza — treatment started (8 seconds)
STEP 13 — Send More Patients
In Terminal 2:

bash
./scripts/triage.sh "Sara Khan"   45  6  1
./scripts/triage.sh "Zain Ahmed"  33  2  0
./scripts/triage.sh "Hina Malik"  55  9  0
Watch Terminal 1 after each one.

STEP 14 — Stop the Hospital
In Terminal 2:

bash
make stop
